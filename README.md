🎮 Tic-Tac-Toe
-----------------
A simple and modern version of the classic Tic-Tac-Toe game made with HTML, CSS, and JavaScript.
Play as X or O, challenge your friend, and enjoy smooth glowing animations when you win.

How to Play
------------
--> Open the index.html file in your browser.
--> Player X starts first — click on a square to make your move.
--> Get three in a row to win.
--> Click "Start New Game" to play again.

Tech Stack
----------
HTML for structure
CSS for design and animation
JavaScript for game logic

Features
--------
Clean dark mode design
Smooth animations and glowing effects
Responsive layout for all devices
Instant restart button
